## 🚀 Como instalar e executar

**Não é necessário instalar nada.**

1. Clique no botão **BAIXAR SISTEMA** acima.
2. Salve o arquivo `index.html` no computador.
3. Abra o arquivo com Chrome, Edge ou Firefox.
4. Selecione um usuário de demonstração no cabeçalho e comece a testar.

> Se o navegador exibir o código em vez de baixar, use a opção **Salvar como** e salve com extensão `.html`.

## 👤 Perfis para testes

No seletor de usuários do cabeçalho, escolha:

- **Administrador** — Militar: cria, edita e exclui páginas.
- **Operador** — Militar: consulta e comenta.
- **Colaborador** — Civil: consulta e comenta.

Esses perfis são apenas uma simulação de interface: **não constituem um sistema seguro de login ou autorização**.

## 🔎 Como pesquisar

Use o campo de pesquisa no topo da página.

- `pesquisa`: encontra a palavra nos textos, títulos e tags.
- `"base de conhecimento"`: procura a frase completa.
- `manual pesquisa`: combina termos e exige a presença de ambos.

A pesquisa não diferencia letras maiúsculas e minúsculas ou acentos. Trata-se de um mecanismo local para a base carregada no navegador.

## 📝 Como publicar uma página

1. Selecione o perfil **Administrador**.
2. Clique em **Nova página**.
3. Informe o título, o espaço e as tags.
4. Edite o conteúdo usando os botões de formatação.
5. Clique em **Publicar**.

As alterações ficam no armazenamento local do navegador. **Não são sincronizadas entre dispositivos ou usuários.**

## 💾 Como preservar seus dados

Use **Exportar JSON** para guardar uma cópia dos dados. O protótipo atual não oferece importação do backup pela interface; a exportação é uma forma de preservar o conteúdo para uso em futuras versões. Limpar os dados do navegador pode apagar as alterações locais.

## 🔐 Privacidade e segurança

Este repositório contém somente código e conteúdo fictício de demonstração. Não insira dados operacionais reais, pessoais, sigilosos ou institucionais sensíveis no protótipo. A seleção de perfil não é uma autenticação real.

Se o repositório for **privado**, o link de download acima também exigirá que a pessoa tenha permissão de acesso ao GitHub. Para distribuir o arquivo a alguém sem acesso, envie o HTML separadamente ou disponibilize-o em uma hospedagem autorizada.
